# 如何學會學習

> 對應 Goal：`G0.10`, `G0.11`, `G0.12` ｜ 練習預估 2 小時（包含專案與反覆練習，不是閱讀時長）
> 前置：無

## 為什麼學這個

把一次報錯變成下次能重用的調查紀錄。

## 概念

每次練習都完成「預測、執行、比較、縮小、重試」。錯誤訊息包含類型、位置和線索；複製原文搜尋時先移除私人路徑或資料。優先核對官方文件的 Python 版本，不能只因搜尋結果第一名就照貼。

## 動手

從倉庫根目錄執行；獨立 Python 片段先存成練習檔再執行。帶有「你要交付」的命令是作業介面，需要先自己完成程式。

```python
items = ["read", "run"]
print(items[2])
```

### 預期結果

這段會產生 IndexError。list 有兩個元素，合法索引是 0 和 1；改成 `items[1]` 後輸出 run。

## 練習與驗收

建立 learning-log.md，連續七天每天記錄日期、30 分鐘做了什麼、預期、實際輸出、查到的來源、採用與拒絕的修法、明日一步。第一天用本例練习，搜尋完整錯誤名稱並解釋為何改索引有效；後六天用其他課的真實問題。七天尚未過完就保留 G0.12 未完成。

## 常見坑

能重述搜尋結果不等於已修好。修改後用原本失敗的輸入重跑；如果為了讓程式不報錯而刪掉必要功能，問題仍未解決。
