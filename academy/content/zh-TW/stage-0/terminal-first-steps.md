# 終端機與檔案系統：把電腦從黑箱變成工具

> 對應 Goal：`G0.1`, `G0.2`, `G0.3`, `G0.4` ｜ 預計時間：3h ｜ 前置：無（本課就是起點）

## 為什麼學這個

你之後要寫的每一行程式碼，都要在一個叫「終端機」的地方被執行、被報錯、
被修正。圖形介面（滑鼠點點點）像自動駕駛，終端機像方向盤——
先練習查看位置與讀取錯誤，讓後續程式能從正確目錄執行。
本課結束時，你會把「電腦」從一個黑箱變成一件你能指揮的工具。

## 正文章節

### 1. 概念：電腦裡只有「檔案」

先建立一個入門模型：

- **你的電腦是一個巨大的檔案櫃**。每份資料都是一個「檔案」，
  檔案放在「資料夾」（又稱目錄）裡，資料夾可以套資料夾；
- **終端機是一個用文字指揮電腦的視窗**。你打一行命令、按 Enter，
  電腦執行，然後用文字回話；
- **你永遠「站在」某個資料夾裡**。終端機的命令都相對於你站的位置——
  這是常見困惑的來源，也是本課最重要的一句話。

### 2. 動手：五條命令打天下

打開終端機：

- Windows：按 `Win 鍵`，輸入 `PowerShell`，回車；
- macOS：`Cmd + 空格`，輸入 `terminal`，回車；
- Linux：通常是 `Ctrl + Alt + T`。

逐行輸入下面的命令（`$` 是提示符，不用輸入；每行按 Enter 後觀察輸出）：

```
$ pwd            # 我現在站在哪？（print working directory）
$ ls             # 這裡有什麼？（list，Windows 用 dir）
$ mkdir mh-lab   # 建一個練習用的資料夾（make directory）
$ cd mh-lab      # 走進去（change directory）
$ pwd            # 再看看我現在在哪——變了！
```

接著玩檔案：

```
$ echo "你好，終端機" > note.txt   # 把一句話存進檔案
$ ls                               # 看見 note.txt 了
$ cat note.txt                     # 把檔案內容印出來（Windows 用 type）
$ mv note.txt hello.txt            # 重新命名
$ cp hello.txt hello-backup.txt    # 複製一份
$ rm hello-backup.txt              # 刪掉備份（rm 不進回收站！）
$ cd ..                            # 退回上一層資料夾
```

### 3. 概念：相對路徑與絕對路徑

- **絕對路徑**：從檔案櫃頂層寫起的完整地址，
  如 `/Users/你的名字/mh-lab/hello.txt`（Windows 形如 `C:\Users\...\hello.txt`）；
- **相對路徑**：從「你現在站的位置」寫起的地址：
  `.` 是這裡，`..` 是上一層，`mh-lab/hello.txt` 是「這裡面的 mh-lab 裡的 hello.txt」。

自測方法：站在任何資料夾裡執行 `pwd`，把輸出和檔案總管地址欄裡的
路徑對照——兩者是同一個地址的兩種寫法。

### 4. 常見坑

- `rm` 沒有回收站，刪錯就沒了。養成習慣：`rm` 之前先 `ls` 看一眼；
- 命令與參數之間的空格是語法的一部分（`cd mh-lab` ≠ `cdmh-lab`）；
- 路徑含空格/中文時用引號包住：`cd "我的 資料夾"`。
