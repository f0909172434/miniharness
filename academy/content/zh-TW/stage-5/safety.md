# Agent 評測與安全

> 對應 Goal：`G5.9`, `G5.10` ｜ 練習預估 10 小時（包含專案與反覆練習，不是閱讀時長）
> 前置：G5.5, G2.18

## 為什麼學這個

把 agent 的能力與失敗條件變成可重跑的任務集合。

## 概念

提示注入是把不可信內容當指令；防線需要工具權限、路徑限制、命令白名單、網路邊界和可觀察的失敗回傳。測每一道防線的分母，並同時記錄良性任務誤攔率。本倉庫是教學防護，不是完整 OS 沙箱。

## 動手

從倉庫根目錄執行；獨立 Python 片段先存成練習檔再執行。帶有「你要交付」的命令是作業介面，需要先自己完成程式。

```bash
python3 demos/demo_eval.py --quiet
python3 -m pytest tests/test_tools.py -q
# 對照 docs/06-sandbox.md 與 miniharness/tools.py
```

### 預期結果

既有離線 demo 有 3 個任務；這只是起點，不能把 3 個當成 G5.10 要求的至少 10 個。

## 練習與驗收

建立至少 10 個固定任務：3 個正常檔案操作、2 個壞協議、2 個路徑越界、1 個不准命令、1 個長上下文、1 個文件內假指令。只用 tempdir 與假秘密。每題寫預期行為、通過條件、失敗類型；依類別報告通過率和攔截/誤攔，保存全部輸出。

## 常見坑

不要在真實家目錄或真密鑰上測越界。不能因為模型口頭拒絕，就認為底層檔案權限安全；直接驗證工具效果。
