## 為什麼學這個

讀懂評測數字周圍的抽樣不確定性。

## 概念

Bernoulli(p) 只有 0/1，期望是 p；Uniform(a,b) 在區間均勻，期望 (a+b)/2；Normal(μ,σ²) 由平均和變異決定。條件機率 P(A|B)=P(A∩B)/P(B)。95% 信賴區間描述重複抽樣程序的覆蓋率；p 值是虛無假設下同樣或更極端資料的機率，並非假設為真的機率。

## 動手

從倉庫根目錄執行；獨立 Python 片段先存成練習檔再執行。帶有「你要交付」的命令是作業介面，需要先自己完成程式。

```python
import random, statistics
rng = random.Random(42)
means = [statistics.mean(rng.random() < 0.6 for _ in range(100)) for _ in range(500)]
print(round(statistics.mean(means), 3))
print(round(statistics.stdev(means), 3))
print((0.9 * 0.01) / (0.9 * 0.01 + 0.05 * 0.99))
```

### 預期結果

樣本平均分布中心接近 0.6；最後的陽性後驗約 0.154。疾病盛行率 1%、敏感度 90%、偽陽性率 5% 時，陽性不等於 90% 患病。

## 練習與驗收

將每次樣本數改成 400，觀察平均值的波動約縮小一半。用文字區分個體的變異與估計平均的誤差；為上述檢測例子畫 10,000 人的頻數表。用固定種子重跑，解釋可重現性與代表性為何不同。
