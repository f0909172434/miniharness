## 為什麼學這個

用形狀與內積讀懂模型的線性層。

## 概念

向量可表示一筆資料的多個特徵，也可表示幾何位移；矩陣可放一批資料或一個線性映射；張量是更一般的多軸陣列。矩陣乘法的內部維度必須相同。內積同時受到方向與長度影響，先正規化才得到 cosine similarity。

## 動手

從倉庫根目錄執行；獨立 Python 片段先存成練習檔再執行。帶有「你要交付」的命令是作業介面，需要先自己完成程式。

```python
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[2, 0], [1, 2]])
print(A @ B)
x = np.array([1., 0.])
y = np.array([2., 0.])
print(x @ y, (x @ y) / (np.linalg.norm(x) * np.linalg.norm(y)))
```

### 預期結果

矩陣結果 [[4,4],[10,8]]；內積是 2、cosine 是 1。本階段另需安裝 academy/requirements-ml.txt；不影響 harness 的零執行依賴。

## 練習與驗收

先手算四個矩陣元素再執行。設定 X 為 (5,3)、W 為 (3,2)、b 為 (2,)，解釋 X@W+b 的 (5,2)；刻意轉置 W 查看形狀錯誤。比較平行但長度不同的向量，解釋內積不能單獨當純方向相似度。

## 常見坑

NumPy 的 * 是逐元素相乘，@ 才是矩陣乘法。零向量的 cosine 分母為零，需要明確處理。
