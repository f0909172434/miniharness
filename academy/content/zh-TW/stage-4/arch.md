## 為什麼學這個

依資料結構選模型，而不是看到新名稱就換架構。

## 概念

CNN 以共享卷積核找局部模式，適合影像與平移結構；RNN 逐步更新隱狀態，適合串流但訓練時間步較難平行；Transformer 用 attention 在序列位置間交換資訊，訓練時可平行處理，標準全注意力成本對長度呈平方成長。生成下一個 token 仍是自回歸逐步進行。

## 動手

從倉庫根目錄執行；獨立 Python 片段先存成練習檔再執行。帶有「你要交付」的命令是作業介面，需要先自己完成程式。

```python
lengths = [32, 64, 128]
for n in lengths:
    print(n, {"local_kernel_3": n*3, "full_attention_pairs": n*n})
```

### 預期結果

長度加倍時，局部核示意操作數加倍，全注意力配對數變四倍。這不是包含全部層、硬體與實作的速度測量。
